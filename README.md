# DLAI_2026_Project_Semerano
This project addresses the Sound Event Detec- tion (SED) task for the Kaggle BirdCLEF+ 2026 competition. Two custom CNN architectures based on Mel spectrograms were designed and trained from scratch. Their effectiveness is eval- uated both individually and combined in an en- semble, as well as compared against an ensem- ble of pre-trained models.
